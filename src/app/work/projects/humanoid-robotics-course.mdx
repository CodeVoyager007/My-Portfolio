# Physical AI Humanoid Robotics Course

This platform is a dedicated educational resource for students and enthusiasts interested in Physical AI and Humanoid Robotics. It provides a structured curriculum, interactive resources, and latest updates in the field.

## Key Features

- **Structured Curriculum**: Organized modules covering various aspects of robotics and AI.
- **Interactive Resources**: Engaging content to facilitate better learning.
- **Responsive Design**: Accessible on all devices for learning on the go.

## Technologies Used

- **Next.js**: Powering the platform with server-side rendering and static site generation.
- **React**: For building interactive UI components.
- **Tailwind CSS**: Ensuring a modern and consistent design language.

## Goal

The goal of this project is to democratize access to advanced robotics education, making it easier for anyone to start their journey in Physical AI.
